They were accurate when written, but the code has moved on. They still use the old
*InfraWatch* name, reference files that no longer exist (`AppLight.tsx`,
`main.light.tsx`, `DockerDashboardLight.tsx`, `trivyApi.ts`), and describe an earlier
authentication model. Some claims are now wrong, for example "all GET endpoints are
protected" and the `token_plain` column.
